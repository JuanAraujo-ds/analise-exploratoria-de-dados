# Análise Exploratória de Dados 🔎📊

Este repositório reúne projetos de Análise Exploratória de Dados (EDA), com foco em extrair insights valiosos e identificar padrões em conjuntos de dados reais. 
O objetivo principal é consolidar o domínio de fundamentos estatísticos e ferramentas de visualização em Python.
